# Mondrian-Inspired CSS Grid Art

[![HTML5](https://img.shields.io/badge/HTML5-markup-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS Grid](https://img.shields.io/badge/CSS-Grid-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A static geometric-art exercise inspired by Piet Mondrian's abstract compositions. The layout is built with HTML elements and CSS Grid, using rectangular color blocks and black gaps to form the composition.

## Project Files

- `index.html` — main implementation, with CSS embedded in the page.
- `solution.html` — alternate/reference implementation.
- `goal.png` — visual target/reference.
- `dimensions.png` — layout sizing reference.

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Open `solution.html` to compare the reference layout.

No build tools, external libraries, or JavaScript are required.

## Concepts Practiced

- CSS Grid rows, columns, gaps, and grid placement.
- Using CSS classes to represent differently colored regions.
- Centering a fixed-size composition with Flexbox.
- Translating a visual target into HTML and CSS.

## Known Limitations

- The layout uses hard-coded grid dimensions and is not fully responsive on smaller screens.
- Styling is embedded in each HTML file, so rules are duplicated.
- The main implementation differs from the reference in some grid placements and colors.
